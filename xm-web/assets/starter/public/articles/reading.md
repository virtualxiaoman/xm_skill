# 让 Markdown 变得好读

这是一篇**虚构演示文章**，用来验证排版与交互。站点的个性来自留白、节奏和清晰的内容层次。

## 代码，应该可以直接带走

行内变量 `learning_rate` 与正文保持接近的字号。复制右上角代码按钮，应该得到原始内容。

```python
import math

def sigmoid(x):
    return 1 / (1 + math.exp(-x))

print(sigmoid(0.5))
```

忠实模式默认也解析代码中的美元公式。Shell 与货币场景如需保持字面值，可在调用方显式设置 codeFormulas:false；以下是边界演示：

```bash
echo "$HOME"
printf '$100 and $200\n'
```

## 公式，也保留它的源头

行内公式 $E = mc^2$ 不应挤乱段落。悬停公式左上角，可以复制带定界符的 LaTeX。

$$
\mathcal{L}(\theta) = -\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(y_i\mid x_i)
$$
