## 源码核对发现的限定

- 原 bracketHighlight 的正文/代码只处理基础括号；`⟨⟩`、`∣‖∥|` 额外字形主要在公式上下文支持。规范保留了要求；不要夸大为所有上下文都支持全部字形。
- 公式按钮实际“进入立即显示、离开延迟 0.5s 隐藏”，不是悬停 0.5s 才显示。详细规范已纠正这条注释歧义。
- 原 mdViewer 的整条选区复制已经实现，但不能把原文件复制入资源就报告骨架已启用；依赖、事件、源码索引与清理要实际接线。
- data-sec 是文章内当次标题顺序，前面增加章节可使序号改变；“精确定位”不等于可永久稳定外链。

当前更新任务是把详细要求纳入 skill 并纠正冲突默认值，不是修改原博客或宣布完成全部新网站功能。后续使用 skill 交付完整网站时，以上未接线项属于完成前必须补齐的范围。
