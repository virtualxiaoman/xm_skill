# 组合与网站约定

## 依赖与职责

路径相对于本 skill；依赖不在同级目录时按已配置的 skill roots 定位。

| 任务 | 读取并应用 | 作用 |
| --- | --- | --- |
| 教学讲解、答案推理、可视化注释 | [xm-note](../../xm-note/SKILL.md) 的规则及内嵌示例 | 直觉、符号、推导、shape、具体例子与连贯表达 |
| 网站或阅读界面 | [xm-web](../../xm-web/SKILL.md)；其 [requirements](../../xm-web/references/requirements.md)、[design-system](../../xm-web/references/design-system.md)、[implementation-status](../../xm-web/references/implementation-status.md)、[acceptance](../../xm-web/references/acceptance.md) | 浅色视觉、完整阅读交互、实际覆盖与验收 |
| 复杂教学示意图 | [drawio](../../drawio/SKILL.md) | 可编辑的源图和适合在讲解或解析中嵌入的 PNG |
| Markdown、公式、图表、复制 | xm-web 的 [markdown-pipeline](../../xm-web/references/markdown-pipeline.md)；迁移组件时另读 [ADAPTATION](../../xm-web/assets/reference-components/ADAPTATION.md) | 统一渲染与源码保真 |

xm-learning 负责学习结构、证据、题目和解析质量、可视化准确性及三界面联动。以当前实际安装的依赖入口定位参考资料；xm-note 的讲解示例直接在其 SKILL.md 中，不要求不存在的额外文件。用户指定的范围、框架与偏好优先，事实准确性优先于风格。

## 完整网站的功能约定

以下适用于完整网站；局部任务仅实现用户要求的部分。沿用既有项目框架与合适依赖，不因复用 starter 重建整个应用。

| 主界面 | 内容与行为 |
| --- | --- |
| Study 学习 | 章节目录、学习重点与测评重点、详细讲解、体现前置/比较/实现关系的知识图谱；从知识点进入相应测验、解析和入选可视化。目录、图谱和策略归入此界面。 |
| Testing 测验 | 单章/多章/综合测验，知识点/题型/难度筛选，随机练习、错题复习；上下题、修改答案、标记、未答提示、保存与提交。学习模式可即时反馈，考试模式提交前隐藏正确答案、解析和参考解法。 |
| Answers 答案 | 按测验/章节/知识点/题型/难度复习全部题目或错题；保留完整原题、选项与代码，显示用户答案、正确答案、正误、完整解析和来源；链接准确的 Study 段落与相关可视化。 |

章节配置提供可键盘操作的“全选章节”，显示选中数；保留手动选择、其他筛选、题数、排序、模式和当前答题记录，全选本身不启动测验。无筛选/数量限制时，综合测验覆盖所有有题目的选中章节。

章节、知识点、题目、可视化和来源使用稳定 ID；深链接与标题锚点建立映射。切换界面保留相关章节、题目和筛选。本地保存作答次数、正确次数、最近结果、曾错记录及复习标记，展示章节完成度、正确率和错题；内容版本变化时保留兼容记录，说明必要的迁移或重置。默认无需账户、云同步、自适应出题或题库管理后台。

## 呈现与可视化

- Study、题面/选项、Answers、预览共用 xm-web 的浅色设计与 Markdown 流水线。长文使用规定阅读布局，局部题目使用 compact；页面文案保留功能、内容与必要操作状态，删除口号与重复介绍。
- Markdown 源码为权威内容，支持代码高亮、美元符号 LaTeX、Mermaid、表格、稳定目录与适用的阅读交互。保留 HTML 消毒、危险 URL 限制、部署 base、资源处理与异步清理。精确视觉和渲染顺序以 xm-web 为准，不复制另一套近似规范。
- 复制知识点、题目或完整答案返回对应原 Markdown，保留公式、缩进、代码和来源。答案复制包含完整推理；题面复制只含允许公开的题面。考试中的跨页查看、预览、导出与可视化均遵守当前答案可见性。
- 每个知识点按收益选择零个、一个或多个可视化。先确定要解释的机制、控制关系和中间状态，静态图遵循 [教学绘图](../SKILL.md#教学绘图) 的分工，交互演示按需使用 SVG 或 Canvas。文字、公式、数值与当前步骤同步；暂停/分步/参数控件按需提供。数学逻辑与显示分离，简化必须说明，调整参数后结果仍须正确。
- 可视化嵌入知识点，解析按需复用；提供静态解释，支持窄屏、键盘及减少动态效果，不仅靠颜色传意。无需为满足章节数量制作动画，也无需为简单演示搭通用引擎。

## 运行检查

在项目现有检查基础上，验证已实现范围：

- 三个主路由、知识点定位、Study → Testing → Answers → Study 的上下文；刷新后兼容进度保留。
- 学习模式反馈、考试提交前的所有答案入口、提交后的完整解析；全选章节、筛选与综合覆盖。
- 题面/解析中的公式、表格、代码和图表实际渲染正确，复制源码完整；不安全 HTML/URL 被处理，宽内容局部滚动，窄屏可用。
- 各可视化的数学状态、交互与静态回退；xm-web 验收中适用的阅读、复制、资源及竞态行为。

运行可用的类型检查、构建和聚焦的浏览器验证。如实区分实际通过、未运行与不适用；starter 可运行或字段齐全不能证明内容与交互已完成。
