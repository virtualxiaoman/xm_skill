## 示例一：公式计算题——定义符号并把结果算出来

### 题面

**知识点：梯度下降的一步参数更新。单选题。**

我们用实数参数 $w$ 控制一个模型，目标是减小损失 $f(w)=\frac12(w-3)^2$。$f(w)$ 表示参数取 $w$ 时的误差代价，数值越小越好。

梯度下降按 $w_1=w_0-\eta f'(w_0)$ 更新。其中 $w_0$、$w_1$ 分别表示更新前、后的参数，$\eta$ 是控制更新幅度的学习率，$f'(w_0)$ 是损失函数在 $w_0$ 处对 $w$ 的导数。设 $w_0=1$、$\eta=0.5$，按实数精确计算。完成一次更新后，$w_1$ 等于多少？

- A. $0$
- B. $1$
- C. $2$
- D. $3$

### 解析

**正确答案为 C，更新后的参数是 $w_1=2$。**

先理解这一步更新在做什么：导数描述当前位置的损失随参数增大而变化的趋势；梯度下降沿导数的反方向移动，学习率决定移动多少。这里给出了更新规则，我们需要先求当前位置的导数，再代入规则。

对 $f(w)=\frac12(w-3)^2$ 求导，平方项的导数为 $2(w-3)$，内层 $w-3$ 对 $w$ 的导数为 $1$，因此

$$
\begin{aligned}
f'(w)&=\frac12\cdot2(w-3)\cdot1=w-3,\\
f'(w_0)&=1-3=-2,\\
w_1&=1-0.5\times(-2)=2.
\end{aligned}
$$

当前位置的导数为负，减去负数会使参数增大。这与本题目标一致：当 $w=3$ 时损失最小，而从 $1$ 增大到 $2$ 更接近 $3$。代回原损失可核验：$f(1)=2$，$f(2)=0.5$，这一步确实减小了损失。

逐项看：

- A 的 $0$ 可由把梯度取绝对值后直接做减法得到，但更新规则保留导数的符号；这里应减去 $-1$。
- B 的 $1$ 表示没有更新。本题导数为 $-2$、学习率非零，参数会改变。
- C 的 $2$ 是按给定导数和学习率计算的结果。
- D 的 $3$ 是最优参数；本题给定的步长只使参数从 $1$ 移到 $2$。若保持其他条件并把学习率改为 $1$，才会一步到达 $3$。

这道题的误区是把“朝最优值移动”理解为“一步到达最优值”。是否一步到达，取决于损失形状、当前位置和学习率；本题结论限定于给出的函数与参数。

**写作要点：** 题面给出对象、目标、每个符号与作答任务；解析从导数的意义展开，展示求导、代入和数值核验。定义背景不等于提前给出待计算的答案。

## 示例二：代码推演题——交代函数属于什么任务

### 题面

**知识点：Python 嵌套列表的复制与修改。单选题。**

在数据预处理中，我们用一个外层列表保存多个批次，每个批次又是一个整数列表。下面的原创最小教学函数 `copy_and_append` 尝试复制批次集合，然后修改副本：给第一个批次追加整数 $9$，再给外层集合追加新批次 $[0]$。

代码使用 Python 3 的内置列表，无第三方依赖；从所示初始状态运行一次。`batches` 是原集合，`copied` 是函数返回的集合。请判断两次 `print` 的输出。

~~~python
def copy_and_append(batches):
    copied = batches.copy()
    copied[0].append(9)
    copied.append([0])
    return copied

batches = [[1, 2], [3, 4]]
copied = copy_and_append(batches)
print(batches)
print(copied)
~~~

| 选项 | 第一次输出：`batches` | 第二次输出：`copied` |
| --- | --- | --- |
| A | [[1, 2], [3, 4]] | [[1, 2, 9], [3, 4], [0]] |
| B | [[1, 2, 9], [3, 4], [0]] | [[1, 2, 9], [3, 4], [0]] |
| C | [[1, 2, 9], [3, 4]] | [[1, 2, 9], [3, 4], [0]] |
| D | [[1, 2, 9], [3, 4]] | [[1, 2], [3, 4], [0]] |

### 解析

**正确答案为 C。原集合的第一个批次也增加了 $9$，新批次 $[0]$ 只出现在返回的集合中。**

理解这个结果，需要把“外层列表”与“它包含的内层列表”分开。列表的浅复制创建新的外层列表，其中的元素仍引用原来的内层对象。执行 `batches.copy()` 后，`batches` 和 `copied` 是两个外层列表，但它们的第一个元素指向同一个列表，第二个元素也指向同一个列表。

沿代码追踪：

| 执行位置 | `batches` 的内容 | `copied` 的内容 | 发生的变化 |
| --- | --- | --- | --- |
| `copied = batches.copy()` | [[1, 2], [3, 4]] | [[1, 2], [3, 4]] | 外层已复制，内层仍共享 |
| `copied[0].append(9)` | [[1, 2, 9], [3, 4]] | [[1, 2, 9], [3, 4]] | 改动共享的第一个内层列表，两条引用都能看到 |
| `copied.append([0])` | [[1, 2, 9], [3, 4]] | [[1, 2, 9], [3, 4], [0]] | 只改动 `copied` 的外层，原外层没有增加元素 |

所以两行输出依次为：

~~~text
[[1, 2, 9], [3, 4]]
[[1, 2, 9], [3, 4], [0]]
~~~

逐项看：

- A 把浅复制当成了连内层对象也独立的复制。第一个批次仍共享，所以原集合也会看到追加的 $9$。
- B 把两个外层列表也当成了同一个对象。浅复制已创建新外层，因此追加新批次只影响 `copied`。
- C 同时区分了共享的内层对象与独立的外层对象，符合三步执行过程。
- D 假设对共享内层对象的修改只在原集合可见。修改从 `copied[0]` 发起，该对象正是双方共同引用的列表，`copied` 同样能看到 $9$。

如果实际需求是“修改副本时保留原集合的全部内容”，本例可以用标准库 `deepcopy` 做深复制。它会递归复制本例中的嵌套列表，使待修改的内层列表也独立。下面是完整修正示例，区别于上面原程序的行为：

~~~python
from copy import deepcopy

def copy_and_append(batches):
    copied = deepcopy(batches)
    copied[0].append(9)
    copied.append([0])
    return copied

batches = [[1, 2], [3, 4]]
copied = copy_and_append(batches)
print(batches)
print(copied)
~~~

修正后两行输出为：

~~~text
[[1, 2], [3, 4]]
[[1, 2, 9], [3, 4], [0]]
~~~

这里的数据只有列表和整数，深复制能满足所述需求。处理其他对象类型时，还需核实它们的复制行为。判断类似问题时，逐步确认“当前语句修改哪个对象、哪些变量仍引用它”，就能解释变化传播到哪里。

**写作要点：** 给出知识点、实际任务、函数意图、全部代码和输入；函数名与路径承担定位作用。解析展示对象关系和每步状态；提供修复时，同时给出完整代码与新的输出。

## 示例三：比较多选题——条件、机制与干扰项

### 题面

**知识点：同一损失函数下，学习率如何改变梯度下降的行为。多选题，选择所有正确陈述。**

设实数参数为 $w$，损失函数为 $f(w)=\frac12(w-3)^2$。它的最优参数为 $3$。第 $t$ 次更新前的参数记为 $w_t$，其中 $t=0,1,2,\ldots$；初值 $w_0=1$。学习率 $\eta$ 在每次运行中保持固定，并采用以下规则迭代：

$$
w_{t+1}=w_t-\eta(w_t-3).
$$

所有计算按精确实数进行。下列说法哪些正确？“误差”指参数与最优值的有符号差 $w_t-3$，“距离”指 $|w_t-3|$。

- A. $\eta=0.5$ 时，每次更新后距离减半，误差保持负号。
- B. $\eta=1$ 时，第一次更新即到达最优参数 $3$。
- C. $\eta=1.5$ 时，误差正负交替，每次更新后距离减半。
- D. $\eta=2$ 时，增加迭代次数就会逐步收敛到 $3$。
- E. 只要 $\eta>0$，每次更新都会使损失严格减小。

### 解析

**正确答案为 A、B、C。**

比较学习率时，关注每一步如何改变参数到最优值的误差。定义 $e_t=w_t-3$，它表示第 $t$ 步的有符号误差；初始误差 $e_0=1-3=-2$。将更新公式两边减去 $3$：

$$
\begin{aligned}
e_{t+1}
&=w_{t+1}-3\\
&=w_t-\eta(w_t-3)-3\\
&=(1-\eta)(w_t-3)\\
&=(1-\eta)e_t.
\end{aligned}
$$

因此，每走一步，误差都乘上固定的 $1-\eta$。这个系数的绝对值决定距离如何变化，正负号决定是否跨过最优值。逐项代入即可：

| 选项 | $1-\eta$ | 本题的参数序列从哪里开始 | 判断与原因 |
| --- | --- | --- | --- |
| A | $0.5$ | $1,2,2.5,2.75,\ldots$ | 正确。误差每步乘正的 $0.5$，仍为负；距离减半。 |
| B | $0$ | $1,3,3,\ldots$ | 正确。第一次更新就令误差为零，后续保持最优值。 |
| C | $-0.5$ | $1,4,2.5,3.25,\ldots$ | 正确。负号使误差交替变号，绝对值每步减半。 |
| D | $-1$ | $1,5,1,5,\ldots$ | 错误。误差在 $-2$ 和 $2$ 之间交替，距离保持为 $2$，不会趋近最优值。 |

E 错在只检查学习率为正，没有限制更新幅度。把损失改写为 $f(w_t)=\frac12e_t^2$，代入上面的误差关系可得：

$$
f(w_{t+1})=(1-\eta)^2 f(w_t).
$$

对本题的非最优状态，只有当 $|1-\eta|<1$，即 $0<\eta<2$，该次更新才会严格减小损失。$\eta=2$ 时损失不变；例如 $\eta=3$ 时，距离变成原来的两倍，损失变成四倍。已经到达最优值后损失为零，会保持为零，因此“每次严格减小”还需要排除最优状态。

这也说明 C 中跨过最优值仍可收敛，因为距离持续缩小。这里推出的具体范围 $0<\eta<2$ 依赖题目给定的二次函数；换损失函数后，要重新检查更新关系，不能把这个数值范围当成所有模型的固定结论。

**写作要点：** 比较双方处在同一任务与明确条件下；每个选项都有机制、代入或反例。即使先前题目用过同一符号，也在当前题面重新定义，确保随机抽题时仍可独立理解。
